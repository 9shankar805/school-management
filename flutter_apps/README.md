# schoolrepo

Flutter mobile applications for Nepal School Hub management system.

## Applications Included
- **`teacher_apps/`**: Flutter mobile application for teachers and class in-charges (attendance, daily diary, speed call, marks entry ledger, syllabus/lesson planning, leave requests, routine schedule).
- **`parent_app/`**: Flutter mobile application for parents and guardians (student progress, report cards, fees/payments, attendance, homework tracking, notices, direct teacher communication).

## Getting Started
Ensure you have Flutter installed (`flutter --version` >= 3.x).

### Teacher App
```bash
cd teacher_apps
flutter pub get
flutter run
```

### Parent App
```bash
cd parent_app
flutter pub get
flutter run
```
